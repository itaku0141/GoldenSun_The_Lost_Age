# 黄金の太陽 失われし時代 — マップ接続 通し番号版

[黄金の太陽 失われし時代 攻略(裏面)](https://omoteura.com/golden-sun-the-lost-age/) のストーリー攻略マップは、出入口の番号が「相手マップ番号-連番」で分かりにくいため、**両端で同じ通し番号 + 行き先**に置き換えて表示する閲覧補助ページです。

- 画像・攻略内容の出典と権利は元サイトにあります。本リポジトリは画像を含まず、元サイトの画像URLを参照して番号バッジを重ねて表示します。
- 元サイトの運営者から要請があれば、公開を取り下げます。
- 番号は画像から機械的に読み取ったもので、誤りがありえます。片側しか読み取れなかった接続は「？」(要確認)で表示しています。

## 構成
- `viewer/` 生成された閲覧ページ(GitHub Pages で公開)
- `data/` 画像から読み取ったラベル位置・マップ番号
- `tools/build_viewer.py` `python3 -I tools/build_viewer.py data/chart-story01.json`
